## 2. 정책 효과 상세

### 2.1. 가중 평균 ETA와 개선 인구

가중 평균 ETA는 행정동별 대상 인구를 가중치로 사용한다. 후보 적용 후 ETA는 기존 기준 기관과 선택된 후보 중 가장 짧은 값이다.

```text
기준선 가중 평균 ETA = Σ(대상 인구 × 기존 기준 기관 ETA) ÷ Σ대상 인구
후보 적용 가중 평균 ETA = Σ(대상 인구 × min(기존 ETA, 선택 후보 ETA)) ÷ Σ대상 인구
```

| 모드 | 분석 대상 인구 | 선택 조합 | 기준선 ETA | 후보 적용 ETA | 변화 | ETA 개선 인구 |
|---|---:|---|---:|---:|---:|---:|
| 소아 | 126,483명 | 후보 1·3·4 | 15.932분 | 12.969분 | -2.963분(-18.60%) | 53,353명(42.18%) |
| 어르신 | 529,419명 | 후보 1·2·3 | 11.890분 | 11.155분 | -0.735분(-6.18%) | 62,260명(11.76%) |

**해석:** 소아 모드는 평균 ETA와 개선 인구 비율 모두에서 더 큰 상대 개선을 보인다. 어르신 모드는 기준선 접근성이 상대적으로 높아 동일한 후보 수를 추가해도 개선 폭이 작다. 정책 우선순위를 정할 때는 절대 개선 인원과 상대 개선율을 함께 봐야 한다.

### 2.2. 15분·30분 모델 커버율

이 보고서의 모델 커버율은 기존 기관과 후보를 합친 뒤, 행정동 중심점에서 가장 짧은 일반 차량 ETA가 임계시간 이내인 대상 인구 비율이다.

| 모드 | 15분 기준선 | 15분 후보 적용 | 변화 | 30분 기준선 | 30분 후보 적용 | 변화 |
|---|---:|---:|---:|---:|---:|---:|
| 소아 | 42.94% | 66.25% | +23.31%p | 97.86% | 98.72% | +0.86%p |
| 어르신 | 79.37% | 84.24% | +4.87%p | 94.16% | 95.30% | +1.14%p |

**해석:** 30분 기준은 이미 기준선 커버율이 높아 후보 간 정책 효과를 구분하는 KPI로는 변별력이 낮다. 현재 후보 비교에는 가중 평균 ETA와 15분 커버율을 우선 사용하고, 30분 커버율은 외곽권 누락을 감시하는 보조 지표로 사용하는 편이 타당하다.

저장된 최적화 결과의 `covered_15min_ratio`와 `covered_30min_ratio`는 **후보 자체의 도달권**을 계산한다. 예를 들어 소아 MCLP 30분 후보 도달권 89.904%는 기준선 대비 순증가율이 아니다. 기존 기관까지 포함한 전체 체계의 전후 비교에는 위 표의 재산출 커버율을 사용해야 한다.

### 3.2. 해석에 영향을 주는 품질 이슈

1. **운영정보 확인 상태:** 외부 원천 상태의 마지막 확인은 2026-07-18이다. 병원 운영정보는 API 또는 일일 스케줄러로 갱신할 수 있으므로 시민 안내 전 재확인이 필요하다. 이 확인 지연은 정적 정책분석본의 유효성과 분리하며, 원천 변경이 있을 때만 분석 대기 후 승인된 재분석으로 반영한다.
2. **인구 원천 공표주기:** 주민등록 인구는 매월 말일 작성 후 익월 1일 12시 이후 공표된다. 따라서 2026-07-26의 최신 완료월은 2026.06이다. 기존 `degraded`는 미공표 2026.07을 먼저 요청한 수집 로직과 CSV 검증본 사용 상태이며, 분석 기준월 지연을 뜻하지 않는다.
3. **운영·정책 소아 기관 수 차이:** 공개 정책 릴리스는 검증된 소아 기준 기관 6곳을 사용하지만, 마지막 `moonlight_pediatric` 운영 원천 상태의 레코드 수는 1건이다. 화면은 이미 변동 운영정보와 기준자료 기반 정책분석을 분리한다. 두 원천의 범위와 갱신 시점을 맞추지 않은 채 합산하거나 증감 비교하지 않는다.
4. **VDI의 구조적 편향:** 현재 VDI는 `ln(1 + 일반 차량 ETA) × 취약인구`다. EDA에서 VDI와 취약인구의 상관은 0.915, ETA와의 상관은 0.034다. 인구 로그 대안은 기준선과 순위상관 0.518·상위 10개 겹침 2/10, 동일가중 정규화 대안은 0.935·7/10으로 확인돼 산식 선택에 따라 우선순위가 달라진다. 따라서 VDI만으로 외곽 접근성 개선을 평가하지 않는다.
5. **고위험 38곳은 성과값이 아님:** 위험 임계값 13,261.43은 150개 행정동의 상위 25%를 나누는 상대 경계다. 고위험 행정동 38곳이라는 값은 정의상 만들어지는 진단 구간이며, 감소 목표나 정책 성과로 사용하려면 별도의 전후 비교 계약이 필요하다.
6. **좌표 보정의 집중:** 460건은 출발지 5곳·목적지 33곳에 집중됐고, 소아 후보 6과 어르신 후보 2가 각각 목적지 보정 150건을 차지한다. 따라서 460개의 독립 위치 오류처럼 해석하지 않고 후보별 보정 의존도를 함께 감시한다.
7. **최근접 기관 ETA 동률:** 달서구 본리동에서 구병원과 열린아동병원이 5.62분으로 동률이다. 수치 영향은 없으며, 향후 재생성에서는 ETA 다음에 기관 키를 정렬해 표시 기관을 고정한다.

| 긴급 액션 전환율(EACR) | 병원 상세를 본 적격 세션 중 전화 또는 길찾기를 1회 이상 실행한 고유 세션 비율 | `hospital_detail_view`, `call_click`, `navigation_click`, 익명 세션 ID | 계측 필요 | 2주 기준선 수집 후 승인 |
| 초도 긴급 액션 시간(TTFA) | 위치 기반 최근접 병원 결과가 준비된 시점부터 첫 전화·길찾기까지의 p50·p90 시간 | `nearest_hospital_ready`, 긴급 액션 이벤트 | 계측 필요 | 기기·네트워크 구간별 기준선 후 승인 |
| Fallback 정상 제공률 | fallback이 필요했던 요청 중 경고와 함께 사용 가능한 대체 데이터를 제공한 요청 비율 | upstream 실패, fallback 유형, 렌더 성공, 캐시 나이 | 계측 필요 | 정상 제공률과 최대 캐시 나이를 함께 승인 |
| API 응답시간 | 핵심 읽기 API별 서버 처리시간 p50·p95·p99 | 경로, 상태 코드, 처리시간, 요청 ID | 계측 필요 | 엔드포인트별 기준선 후 승인 |
| 화면 반응성 | 모바일·데스크톱별 LCP와 INP의 p75 | 실사용 환경 웹 성능 이벤트 | 계측 필요 | 기기군별 기준선 후 승인 |

**지표 설계 보정:** 기존 EACR 산식처럼 클릭 수를 세션 수로 나누면 한 세션의 중복 클릭 때문에 100%를 넘을 수 있다. 분자는 긴급 액션을 한 고유 적격 세션으로 고정한다. TTFA는 위치 권한 승인 시점이 아니라 최근접 병원 결과가 실제로 준비된 시점부터 측정해 사용자·브라우저 권한 지연을 분리한다.

## 6. 운영 계약

| 항목 | 확정 기준 | 운영 이유 |
|---|---|---|
| 정기 보고 주기 | 주 1회, 정책 릴리스 변경 또는 원천 장애 시 수시 보고 | 24시간 최신성 계약 위반과 릴리스 변화를 운영 회의 전에 확인 |
| 1차 최적화 목적 | 취약인구 가중 평균 ETA 최소화(p-median) | 후보 적용 전후의 평균 접근성 변화를 직접 비교 |
| 1차 의사결정 보조 KPI | 기존 기관을 포함한 전체 체계의 15분 커버율 | 평균 개선이 일부 지역의 시간권 악화를 숨기는지 함께 확인 |
| 보조 가드레일 | 전체 체계의 30분 커버율 | 기준선부터 높아 후보 변별력은 낮지만 외곽권 누락을 감시 |
| 정책 KPI 책임자 | 프로젝트 제품·분석 책임자(Accountable) | 지표 정의·비교 조합·정책 해석과 목표 승인 책임 |
| 데이터 품질 책임자 | 데이터 파이프라인 담당(Responsible) | 외부 원천 최신성, fallback, 키·좌표·경로·산식 검사 책임 |
| 서비스 KPI 책임자 | 서비스 운영 담당(Responsible), 제품·운영 책임자(Accountable) | 이벤트·성능 계측과 2주 기준선 이후 목표 승인 책임 |
| 목표 상태 | 정책·서비스 모두 승인 전 | 현재 정책 수치는 `개선·목표 미승인`, 서비스 수치는 `계측 필요`로 유지 |

### 남은 외부 의존 결정

- 소아 기준 기관의 동적 원천 1건과 검증된 정적 기준 6곳을 통합하는 규칙은 원천 범위·운영시간·중복 제거 기준을 확인한 뒤 책임자가 승인해야 한다. 이 결정 전에는 두 수치를 직접 합산하거나 증감 비교하지 않는다.

## 7. 가정과 한계

- ETA는 단일 수집 시점의 일반 차량 경로이며 119 구급차 우선통행, 출동 준비시간, 실시간 교통 변동을 반영하지 않는다.
- 모델은 병상, 의료진, 장비, 진료과 운영시간과 실제 환자 수용 여부를 반영하지 않는다.
- 행정동 중심점은 대표 좌표이며 실제 환자 위치가 아니다.
- 후보는 현장조사 우선순위이며 확정 부지나 시설 신설안이 아니다.
- 현재 보고서는 단일 릴리스의 기준선 대비 시뮬레이션이다. 이전 운영 기간과의 시계열 증감은 제공하지 않는다.
- 승인된 사업 목표가 없어 정책 효과는 `개선·목표 미승인`으로 표시했다.
