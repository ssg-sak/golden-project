# 대구 골든타임·골든 거버넌스 5분 면접 설명 자료

## 한 문장 정의

공공 응급의료 접근성 문제를 직접 정의하고, 데이터 수집·공간 후보 생성·시설입지 최적화·도로 ETA 평가·서비스·배포·갱신·검증까지 단독으로 연결한 공간분석 의사결정 지원 프로젝트입니다.

예측 정확도를 겨루는 AI 모델 프로젝트가 아니라, 제한된 후보와 정책 목적함수 안에서 대안을 비교하는 **공간분석·시설입지 최적화 프로젝트**입니다.

## 0:00~0:40 문제 정의

“병원이 몇 곳 있는가”나 직선거리만으로는 강·철도·간선도로 우회와 취약인구 분포를 설명하기 어렵습니다. 그래서 시민에게는 현재 위치에서 확인할 기관 정보를, 정책 검토자에게는 150개 행정동의 보호가 필요한 인구와 실제 도로 ETA를 결합한 후보 비교 근거를 제공하도록 문제를 나눴습니다.

핵심 의사결정 질문은 다음과 같습니다.

> 기존 기관을 유지한 상태에서 제한된 정책 후보를 추가하면, 보호가 필요한 인구의 평균 접근시간과 15분 내 접근 가능 인구가 어떻게 달라지는가?

## 0:40~1:40 분석 흐름

1. 행정동 중심점과 소아·고령층 인구를 분석 단위로 정리했습니다.
2. 직선거리는 1차 사각지대 탐색과 후보 생성에만 사용했습니다.
3. K-Means를 여러 K·시드·거리·군위 조건에서 반복해 안정적인 후보권을 만들었습니다.
4. 150개 행정동에서 25개 기준 기관과 9개 후보까지 5,100개 도로 경로를 수집했습니다.
5. 후보군 안에서 p-median과 MCLP의 1~3개 조합을 전수 비교했습니다.
6. 결과를 단일 정책 릴리스로 묶어 API·웹·PDF가 같은 정본을 사용하도록 했습니다.

## 1:40~2:40 핵심 결과와 해석

현재 정본은 Release `2026-07-r1`, 인구 기준월 `2026.07`입니다.

| 대상 | 취약인구 가중 평균 ETA | 전체 체계 15분 커버율 |
|---|---:|---:|
| 소아 | 16.237분 → 13.286분 | 41.44% → 64.01% |
| 어르신 | 12.034분 → 11.269분 | 79.19% → 84.00% |

가중 평균 ETA는 효율성, 15분 커버율은 제한시간 내 형평성을 보는 지표입니다. 두 값을 하나로 합치지 않고 함께 제시했습니다. 이 수치는 승인된 사업 효과가 아니라 기존 기관과 후보를 비교한 정책 시뮬레이션입니다.

## 2:40~3:30 검증과 재현성

차별점은 테스트 개수 자체가 아니라 공개 가능한 분석본의 계약입니다.

- 행정동 150개, 기준 기관 25개, 후보 9개, 경로 5,100개가 모두 있어야 합니다.
- 경로 누락, 좌표 이탈, 키 불일치, VDI 재계산 오차가 있으면 생성이 중단됩니다.
- 기관·취약도·후보·최적화·경로 결과의 SHA-256을 릴리스에 기록합니다.
- CI가 정책 릴리스와 EDA를 다시 만들고 커밋된 결과와 차이가 없는지 검사합니다.

이 검증은 **같은 입력과 코드에서 같은 내부 분석 결과가 나오는 것**을 보장합니다. 원천자료의 최신성, 구급차 이동시간, 병원 수용 가능성, 정책 효과까지 보장하지는 않습니다.

## 3:30~4:20 한계와 외부 운영자료 점검

VDI는 `ln(1 + ETA) × 취약인구`이므로 취약인구와의 상관이 0.933, ETA와의 상관이 0.041입니다. 따라서 확정 정책 순위가 아니라 1차 스크리닝 지표로 제한하고, 가중 ETA·15분 커버율·후보 안정성을 함께 사용했습니다.

또한 대구소방안전본부의 공개 구급 관제 표본 2,010행을 이용해 구급차 400건의 `출동보고→현장도착보고`를 재구성했습니다. 세 주요 시간대 중앙값은 모두 5분이었지만 90백분위는 8.0~11.4분이었습니다. 시간 변동 가능성을 보여주는 참고 근거이지만, 사고 좌표와 병원 목적지가 없어 현재 행정동→병원 ETA의 직접 오차 검증은 아닙니다.

## 4:20~5:00 개인 기여와 마무리

문제 정의, 분석 기준 선택, 데이터 계약, GIS·최적화 구현, 백엔드·프론트엔드, 테스트, 배포, 문서화를 개인이 수행했습니다. 생성형 AI는 코드·문서 작성 보조로 사용했지만, 어떤 방법을 채택할지와 결과의 한계를 어디까지 공개할지는 직접 판단했습니다.

마무리 문장:

> 모델 하나를 구현한 것이 아니라, 공공 문제를 데이터와 공간 의사결정 문제로 바꾸고 결과의 재현 범위와 정책적 한계까지 책임지는 전체 흐름을 완성했습니다.

## 반드시 설명할 수 있어야 하는 여섯 가지

### 1. 왜 직선거리와 도로 ETA를 두 단계로 나눴는가?

직선거리는 모든 후보를 빠르게 탐색하기 위한 저비용 근사치이고, 도로 ETA는 최종 후보 조합의 실제 도로망 접근성을 비교하는 고비용 평가값입니다. 처음부터 모든 탐색을 API 경로로 수행하면 호출비용·재현성 부담이 커지므로 역할을 분리했습니다.

### 2. VDI의 약점은 무엇인가?

취약인구가 원값으로 곱해져 인구 규모의 영향이 강합니다. 현재 자료에서도 VDI-취약인구 상관 0.933, VDI-ETA 상관 0.041입니다. 대안 산식에 따라 상위 10개가 크게 바뀌므로 최종 순위가 아닌 스크리닝 지표로 사용합니다.

### 3. K-Means와 p-median의 차이는 무엇인가?

K-Means는 직선거리 공간에서 반복적으로 나타나는 1차 후보권을 생성합니다. p-median은 만들어진 후보군 안에서 취약인구 가중 평균 도로 ETA를 가장 작게 만드는 후보 조합을 찾습니다. 후보 생성과 최종 조합 비교의 역할이 다릅니다.

### 4. 15분 커버율과 ETA 개선 인구의 차이는 무엇인가?

15분 커버율은 기존 기관과 후보 중 하나라도 15분 안에 도달 가능한 전체 대상 인구의 비율입니다. ETA 개선 인구는 후보를 추가했을 때 기존보다 더 짧은 경로를 얻은 인구입니다. 시간이 줄었어도 여전히 15분 밖일 수 있고, 이미 15분 안인 사람은 커버 상태가 변하지 않을 수 있습니다.

### 5. 후보군 내부 정확해와 전역 최적해의 차이는 무엇인가?

9개 후보에서 1~3개를 고르는 모든 조합은 전수 비교했으므로 **후보군 안에서는 정확해**입니다. 그러나 대구 전역의 모든 좌표를 후보로 비교하지 않았기 때문에 전역 최적해는 아닙니다.

### 6. 5,100개 경로 해시는 무엇을 보장하는가?

저장된 행정동-기관·후보 경로 결과가 릴리스 당시 값과 동일한지 탐지합니다. 경로 누락이나 파일 드리프트를 막지만, Kakao 경로가 실제 구급차 이동을 정확히 대표하는지나 이후 교통상황 변화까지 보장하지 않습니다.

## AI 활용 질문에 대한 답변

“생성형 AI를 보조 도구로 사용했습니다. 다만 생성 결과를 그대로 채택하지 않고, 정본 데이터와 재계산 결과를 대조하고 테스트·CI·해시로 검증했습니다. 특히 VDI 편향, 단일 시점 ETA, 후보군 내부 정확해라는 한계를 문서에 남겼습니다. 제가 직접 설명할 수 없는 기능이나 분석 주장은 포트폴리오 근거로 사용하지 않습니다.”
