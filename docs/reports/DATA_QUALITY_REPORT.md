## 4. 주요 발견과 영향

### 4.1. 운영 원천 확인 기록 지연

- **처리 상태:** **운영 확인 필요** — 갱신·상태 분리 코드와 로컬 스케줄러 활성화는 완료됐지만 배포 환경의 활성화와 실제 API 성공 기록이 필요하다.
- **심각도:** 운영 화면 중간, 정적 정책분석 낮음
- **신뢰도:** 높음
- **증거:** 병원·행정동 등 운영 원천의 마지막 성공 또는 확인 기록은 2026-07-18이며 보고 기준일은 2026-07-26이다. 응급기관과 달빛어린이병원은 각각 일일 03:00·03:15 스케줄과 수동 갱신 파이프라인이 구현돼 있지만 기본 환경에서는 스케줄러가 비활성화돼 있다.
- **영향:** 최신 병원 운영상태를 전제로 한 시민 안내에는 재확인이 필요하다. 다만 2026-07-r1 정적 정책분석은 별도 기준자료·경로·해시로 검증됐으므로 운영 API 확인 지연만으로 무효가 되지 않는다.
- **조치:** 배포 환경에서 자격증명·운영 로그·실패 알림을 확인한 뒤 병원 스케줄러를 활성화하거나 인증된 갱신 API를 실행한다. 원천 값이 변경되면 `analysis_pending`을 확인하고, 정책 기준자료 반영이 승인된 경우에만 `rebuild-analysis`를 실행한다. `/api/dashboard/data-status`는 운영 원천 상태와 분석 대기 상태를 계속 별도로 반환한다.

### 4.2. 인구 공표주기와 API fallback

- **처리 상태:** **후속 보완 완료(실수집·자동 차단 검증)** — 2026-08-03 새 API 활용신청 승인 후 `admmPpltnHhStus/selectAdmmPpltnHhStus` 실호출에 성공했다. `202606` 공식 응답을 프로젝트 기준 150개 행정동으로 적재했으며, 월간 연령별 자동 확인기는 미완성 `202607` 응답을 정식 반영 전에 차단했다.
- **심각도:** 데이터 시점 낮음, 수집 상태 중간
- **신뢰도:** 높음
- **증거:** 2026-08-03 13:19(Asia/Seoul) 공식 API에서 `202607`은 `NODATA`, `202606`은 152개 행정단위를 반환했다. 이 중 논공읍공단출장소와 다사읍서재출장소를 각각 논공읍·다사읍에 합산해 총인구 2,348,165명과 성별 합계를 보존하면서 150개 행정동으로 정규화했다. 14:12경 행정안전부 연령별 CSV에는 `2026년07월` 머리글과 150개 행정동 구조가 먼저 나타났지만 총인구·전 연령 값이 모두 0이었다. 시험 실행은 VDI가 0으로 바뀌기 전에 실패했고, 이후 `총인구 합계 0 또는 취약인구 합계 0`을 `공식 자료 공개 대기`로 처리하는 회귀 검사를 추가했다.
- **영향:** 총인구·성별·세대수 운영 스냅샷은 공식 API로 갱신됐지만, VDI는 `65세 이상`과 `0~9세` 공식 입력을 사용하므로 7월 총인구만으로 기준월을 올리면 안 된다. 추가 시험에서 기존 KOSIS 변환기가 두 출장소를 버려 어르신 6,581명·아동 4,434명을 누락한 사실을 확인했다. 공식 연령별 CSV의 나머지 소폭 보정까지 포함한 2026.07 후보는 어르신 536,002명·아동 130,923명이며, VDI 범위 749.83~54,656.78, 고위험 38개, 상대 경계 13,344.69이다. 후보 좌표와 18개 최적 조합은 바뀌지 않았지만 10개 행정동의 VDI가 달라져 현재 공개본은 유지하고 검토 대상으로 분리했다.
- **조치:** 운영 인구 수집기는 미공표 월이면 이전 월을 탐색하고, 인증·활용신청 오류는 즉시 중단한다. 1~7일과 10·15·20·25일 18:00(Asia/Seoul)에 반복하며 같은 해시는 `unchanged`로 종료한다. 월간 정책 분석은 행정안전부의 구·군별 1세 단위 공식 CSV를 별도로 수집하고, 150개 행정동·중복·음수·전체 0값·해시를 검증한 뒤에만 VDI와 화면 기준월을 함께 올린다. 같은 기준월 보정이나 큰 수치 변화는 `change_summary.json`을 남기고 사람의 확인 전에는 정식 반영하지 않는다.

### 4.3. 프론트엔드 좌표 안전 경계

- **처리 상태:** **해결 완료** — 안전 경계 수정과 외곽·외부 좌표 회귀 테스트를 적용했다.
- **심각도:** 수정 전 높음, 수정 후 낮음
- **신뢰도:** 높음
- **증거:** 이전 사각 경계 `35.68~36.26`, `128.38~128.84`는 달성군 구지면과 군위군 소보면 중심점을 제외했다. 안전 경계를 `35.60~36.34`, `128.34~128.91`로 확장한 뒤 중심점 150개와 GeoJSON 꼭짓점 14,991개가 모두 포함됐다.
- **영향:** 수정 전에는 유효한 대구 위치가 외부로 판정돼 대구시청 좌표 fallback으로 전환될 수 있었다.
- **조치:** 구지면·소보면·군위군청 좌표를 회귀 테스트에 고정하고 부산시청 좌표는 계속 거부한다. 이 사각 경계는 행정구역 폴리곤 자체가 아니라 빠른 위치 판정을 위한 안전 경계다.

### 4.4. 좌표 보정 경로의 집중

- **처리 상태:** **통제 완료** — 오류 건수로 제거할 대상이 아니라 특정 출발지·목적지에 집중된 보정 특성으로 분리 보고하고 임계 초과를 자동 차단한다.
- **심각도:** 중간
- **신뢰도:** 높음
- **증거:** 보정 경로는 460/5,100건(9.02%)이지만 보정 출발지는 5곳, 목적지는 33곳이다. 출발지 5곳은 각 34경로이며, `candidate:pediatric:6`과 `candidate:senior:2`는 목적지 보정이 각각 150경로다.
- **영향:** 460건을 서로 독립적인 위치 오류로 해석하면 문제 규모를 과장한다. 반대로 특정 후보에 집중된 보정 의존도를 전체 평균 0.311km만으로 숨길 수도 있다.
- **조치:** 전체 건수와 함께 고유 출발지·목적지 수, 후보별 집중도, 평균·최대 보정거리를 보고한다. 검증기는 보정 상세 460행에서 이 값을 다시 계산하며, 집중도 드리프트 또는 최대 0.75km 초과 시 실패한다.

### 4.5. 최근접 기관 ETA 동률

- **처리 상태:** **해결 완료** — `(ETA, 자원 ID)` 결정 규칙과 회귀 테스트를 적용했다.
- **심각도:** 낮음
- **신뢰도:** 높음
- **증거:** 달서구 본리동에서 구병원과 열린아동병원의 ETA가 모두 5.62분이다.
- **영향:** ETA·VDI·KPI에는 영향이 없지만 입력 순서가 바뀌면 표시 기관명이 달라질 수 있다.
- **조치:** 생성기와 검증기의 최근접 기관 선택 키를 `(ETA, 자원 ID)`로 고정했다. 최소 ETA 중 다른 기관을 저장해도 검증이 실패하는 동률 회귀 테스트를 유지한다.

### 4.6. 운영·정책 소아 기관 범위 차이

- **처리 상태:** **통제 완료** — 서로 다른 모집단을 합치지 않고 API 계약과 화면에서 운영정보·정책 기준자료를 분리한다.
- **심각도:** 낮음(구분 표시 적용), 직접 비교 시 높음
- **신뢰도:** 높음
- **증거:** 정책 릴리스는 검증된 정적 소아 기준 기관 6곳을 사용하지만 `moonlight_pediatric` 동적 원천의 마지막 레코드 수는 1건이다.
- **영향:** 두 수치를 같은 모집단의 전후 변화로 비교하면 잘못된 결론이 되지만, 현재 화면은 이미 변동 운영정보와 기준자료 기반 정책분석을 분리해 설명한다.
- **조치:** 상태 API의 `scopeContracts.pediatricFacilities`는 기계 판정용 계약으로 유지한다. 화면에는 기존의 변동 정보·기준자료 안내를 정본으로 사용하고 같은 내용을 중복 경고하지 않는다. 운영시간·기관 정의·중복 제거·갱신 시점을 맞춘 통합 계약이 승인되기 전에는 합산·증감 비교하지 않는다.

### 4.7. VDI 구조적 민감도

- **처리 상태:** **통제 완료** — 산식의 구조적 특성은 제거하지 않고 대안 순위 민감도와 ETA·15분 커버율을 함께 보고한다.
- **심각도:** 중간
- **신뢰도:** 높음
- **증거:** VDI와 취약인구의 상관은 0.933, 일반 차량 ETA와의 상관은 0.041이다. 인구 로그 곱셈 대안은 기준선과 Spearman 순위상관 0.535·상위 10개 겹침 3/10·최대 134위 이동, 로그 구성요소 Min-Max 동일가중 대안은 0.895·6/10·최대 85위 이동이다.
- **영향:** 현재 순위가 인구가 많은 도시권에 더 민감할 수 있으며, 이 상관을 외부 타당성이나 인과 효과로 해석할 수 없다.
- **조치:** `scripts/vdi_sensitivity.py`가 두 대안의 순위상관·상위 10개 겹침·중앙·최대 순위 이동을 재산출한다. VDI를 확정 서열로 사용하지 않고 가중 평균 ETA·15분 전체 체계 커버율과 함께 보고한다.

### 4.8. 외부 구급 관제 표본의 시간대별 참고 검증

- **처리 상태:** **보조 근거 확보·직접 ETA 검증은 미완료** — 공식 공개 원문과 해시를 보존하고 차량별 상태 전이를 결정적으로 재구성했다.
- **심각도:** 외부 타당성 중간
- **신뢰도:** 표본 내부 집계 높음, 정책 ETA에 대한 외삽 낮음
- **증거:** 2024-08-01 대구소방안전본부 관제 표본 2,010행 중 구급차 이벤트 878행을 사용해 `출동보고→현장도착보고` 400쌍을 만들었다. 전체 중앙값은 4.0분, 90백분위는 10.0분이었다. 07~09시·10~16시·17~19시의 중앙값은 모두 5.0분이었지만 90백분위는 각각 8.0·10.0·11.4분이었다.
- **영향:** 상단 지연 분포가 시간대별로 같다고 가정하기 어렵다는 탐색적 신호다. 그러나 사고 좌표와 이송병원이 없고 구간도 출동센터→현장이므로, 행정동 중심점→병원 일반 차량 ETA의 오차나 정책 후보의 효과를 직접 입증하지 않는다.
- **조치:** `scripts/external_validity_validation.py`와 `tests/unit/ai_model/test_external_validity_validation.py`로 원문 해시·상태 전이·집계를 재현한다. 후속 연구에서는 시간대별 도로 ETA 반복수집 또는 비식별 사고 좌표·이송병원·구급차 시각 자료로 방향성·오차를 비교한다.

### 4.9. 공공데이터 스케줄러·실시간 병상 폴러 호출량

- **처리 상태:** **통제 완료** — 배치 작업에는 고정 Cron·요청 예산·페이지 상한·10분 제한을, 실시간 병상에는 10분 기본 주기·120초 갱신 제한·중복 작업 차단을 적용했다.
- **심각도:** 보강 전 중간, 보강 후 낮음
- **신뢰도:** 높음
- **증거:** 배치 스케줄은 응급기관·달빛어린이병원 각 일 1회, 인구·행정동 각 월 1회로 고정돼 있다. 비정상 응답·재시도·페이지 증가 시에도 실행 1회당 병원 100회, 인구 60회, SGIS 60회를 넘기면 외부 호출 전에 실패한다. 2026-07-26 운영계정 확인 기준 중앙의료원 API는 엔드포인트별 일 1,000회, 나머지 연동 API는 일 10,000회다. 별도 실시간 병상 폴러는 기본 600초, 허용 범위 300~3,600초다. 서버가 계속 실행되는 정상 경로에서 중앙의료원 엔드포인트별 예상 호출은 약 144회/일(14.4%)이다.
- **영향:** 배치 스케줄러만으로 일일 할당량이 급격히 소진되는 구조는 아니다. 병상 폴러의 정적·실시간 병상 엔드포인트가 매 주기 최대 3회 재시도를 모두 소진해도 각각 약 432회/일(43.2%)이므로 확인된 1,000회 한도 안에 남는다. 실제 응답 성공 시에는 재시도를 사용하지 않는다.
- **조치:** 병상 폴러는 기본 600초로 실행하고, 갱신 1회가 120초를 넘으면 취소한다. 배치 작업은 외부 요청별 15~20초 타임아웃과 최대 3회 재시도, 작업 전체 600초 제한을 유지한다. `/health`는 배치 스케줄러와 병상 폴러의 설정·실행 상태와 실제 주기를 각각 반환한다. 계정 한도가 변경되면 600초 주기와 실행별 요청 예산을 함께 재검토한다.

### 4.10. Render 무료 플랜의 휴면과 SQLite 비영속성

- **처리 상태:** **플랫폼 제약 수용** — 정적 검증본은 유지되지만 동적 갱신의 24시간 실행·보존은 보장하지 않는다.
- **심각도:** 최신 운영정보 중간, 정적 정책분석 낮음
- **신뢰도:** 높음
- **증거:** 현재 배포는 Render 무료 Web Service다. [Render 공식 문서](https://render.com/docs/free)에 따르면 무료 Web Service는 15분간 요청이 없으면 중지되고, 중지·재시작·재배포 때 로컬 SQLite를 포함한 파일 변경이 사라지며 영구 디스크를 연결할 수 없다.
- **영향:** 프로세스가 중지된 시간의 Cron 작업은 운영 SLA로 보장할 수 없고, 실행 중 수집한 동적 DB 변경도 다음 인스턴스에 남지 않을 수 있다. 저장소에 포함된 정적 정책 릴리스·EDA·KPI에는 영향이 없다.
- **조치:** 무료 배포에서는 정적 검증본을 정본으로 사용하고 최신 운영정보는 발표 직전 수동 갱신 성공 여부를 확인한다. `/health`의 `databaseStorageMode=ephemeral`을 운영 제약으로 공개하며, 24시간 자동 갱신·보존이 필요해지는 시점에 유료 영구 디스크 또는 외부 DB로 전환한다.

## 7. 가정과 미해결 의존성

- 좌표 안전 경계는 빠른 프론트엔드 판정을 위한 사각형이며 법정 행정구역 포함 여부는 실제 GeoJSON 폴리곤 판정으로 확인해야 한다.
- ETA는 단일 수집 시점의 일반 차량 경로다. 실시간 교통·119 우선통행·출동 준비시간·병상·의료진 수용 여부를 포함하지 않는다.
- 외부 관제 표본은 하루의 출동센터→현장 구간이며 사고 좌표·이송병원이 없다. 시간 변동 가능성의 참고 근거일 뿐 정책 ETA의 직접 오차 검증이 아니다.
- 정책 후보는 현장조사 우선순위이며 확정 부지나 시설 신설안이 아니다.
- 병원 운영 원천은 API 갱신이 가능하지만, 현재 상태 테이블에는 2026-07-18 이후 성공 기록이 없어 배포 환경에서 재실행 결과 확인이 필요하다.
- Render 무료 Web Service의 동적 SQLite 변경과 예약 실행은 휴면·재시작을 넘어 보존되는 운영 SLA가 아니며, 정적 검증본과 분리해 해석한다.
- 2026.07 주민등록 인구는 2026년 8월 공표 후 검증 대상이며, 공표 전에는 2026.07을 최신 완료월로 유지한다.
- 소아 기관 통합 규칙은 아직 승인되지 않았지만, 승인 전까지 두 모집단을 분리하는 API·화면 계약은 적용됐다.
