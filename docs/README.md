# 문서 안내

이 디렉터리는 현재 구현의 기준 문서, 날짜가 고정된 검증 기록, 재사용 양식과 과거 개발 기록을 구분해 관리합니다. 서비스와 분석 결과를 설명할 때는 `CURRENT` 문서를 먼저 확인하고, 수치나 테스트 결과는 작성일이 표시된 `EVIDENCE` 문서에서 확인합니다.

## 문서 상태

| 상태 | 의미 | 관리 원칙 |
|---|---|---|
| `CURRENT` | 현재 구조·방법·데이터 계약을 설명하는 기준 문서 | 기존 문서를 갱신하고 같은 주제의 새 문서를 중복 생성하지 않음 |
| `EVIDENCE` | 특정 시점의 분석·검증 결과 | 작성일과 검증 범위를 유지하며 새 검증은 새 기록으로 남김 |
| `TEMPLATE` | 반복 작업에 사용하는 빈 양식 | 실제 결과와 섞지 않고 입력란을 유지함 |
| `ARCHIVE` | 현재 구현과 다를 수 있는 과거 기록 | 현행 근거로 인용하지 않고 원문과 Git 이력을 보존함 |

## 관리 원칙

1. 한 주제에는 현재 기준 문서 하나만 둡니다.
2. 검증 수치에는 기준일과 실행 범위를 함께 기록합니다.
3. 날짜형 보고서는 과거 결과를 덮어쓰지 않고 새 파일로 추가합니다.
4. 완료되거나 대체된 계획은 `archive/`로 이동하고 현재 문서에서 연결을 제거합니다.
5. 문서 경로를 바꾸면 README, 생성 스크립트, CI와 내부 링크를 함께 수정합니다.
