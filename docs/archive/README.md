# 과거 자료 안내

이 디렉터리는 작성 당시의 맥락을 보존하기 위한 자료입니다. 제거된 기능, 이전 데이터 계약, 완료된 계획과 현재 사용하지 않는 표현이 포함될 수 있으므로 현행 서비스나 분석의 근거로 사용하지 않습니다.

현재 기준은 [문서 안내](../README.md)의 `CURRENT` 문서를 따릅니다.

## 분류

| 경로 | 내용 |
|---|---|
| `legacy-consolidated/` | 과거 문서 169개를 주제별로 이어 붙인 7개 통합 기록 |
| `plans/` | 완료되었거나 현재 저장소 범위를 벗어난 계획 |
| `delivery-evidence/` | 이전 전달물 생성·검증 기록 |
| `repository-history/` | 데이터 무결성 강화와 저장소 분리·정리 이력 |
| `drafts/` | 현재 문서로 채택되지 않은 작성 초안 |

보관 파일은 검색과 이력 확인을 위해 원문을 유지합니다. 통합 전에 존재하던 원본 파일을 가리키는 내부 링크는 현재 저장소에서 열리지 않을 수 있습니다. 현재 문서로 되살릴 내용이 있다면 활성 코드와 정본 데이터를 다시 확인한 뒤 `core/` 문서에 반영합니다.
